# Посты

Через API можно управлять всем жизненным циклом поста: создать, получить, обновить и удалить. Все примеры предполагают, что вы уже [получили токен](../auth.md) и передаёте его в заголовке `Authorization`. Аккаунты, в которые вы публикуете, должны быть подключены в [кабинете](../../accounts/index.md); их идентификаторы берутся из [`listSocialAccounts`](../socials.md).

| Операция               | Метод                         | Страница                                  |
| ---------------------- | ----------------------------- | ----------------------------------------- |
| Создать пост           | мутация `createPost`          | [Создание поста](./create.md)             |
| Получить пост          | запрос `post`                 | [Получение постов](./get.md)              |
| Список постов          | запрос `posts`, `postsCount`  | [Получение постов](./get.md)              |
| Обновить пост          | мутация `updatePost`          | [Обновление поста](./update.md)           |
| Удалить пост           | мутация `deletePost`          | [Удаление поста](./delete.md)             |
| Поля объекта `Post`    | —                             | [Структура Post](./item.md)               |

Мутации требуют активного тарифа и токена с правом записи (не «только чтение»); запросы `post` и `posts` доступны и токену «только чтение».

## Создание

```graphql
mutation {
  createPost(
    post: {
      fields: { text: "Текст поста" }
      networks: { accounts: ["account_id"] }
    }
  ) {
    id
    status
  }
}
```

Подробнее — [createPost](./create.md): медиа, UTM-метки, настройки ВКонтакте и Facebook, расписание, черновики.

## Получение

```graphql
query {
  post(id: "post_id") {
    id
    status
    publishAt
    results {
      accountId
      success
      linkToSocialPost
      errorMsg
    }
  }
}
```

Подробнее — [post и posts](./get.md).

## Обновление и удаление

```graphql
mutation {
  updatePost(id: "post_id", post: { fields: { text: "Новый текст" } }) {
    id
  }
}
```

```graphql
mutation {
  deletePost(id: "post_id") {
    id
  }
}
```

Подробнее — [updatePost](./update.md) и [deletePost](./delete.md).

## Важно знать

1. **Публикация асинхронна.** `createPost` возвращает пост сразу, а результат по аккаунтам появляется позже в `results`; общий итог — в `status`.
2. **Медиа загружаются по ссылке.** Изображения и файлы из `imageUrls` и `fileUrls` сервис скачивает сам, поэтому ссылки должны быть доступны из интернета.
3. **Интервал между постами.** В **Настройки → Посты** задаётся минимальный интервал между публикациями (в секундах, от 1 до 3600; по умолчанию 60). Через API посты можно создавать с любой частотой, но фактическое время отправки сдвигается так, чтобы соблюдался интервал. К автоматизации этот интервал не применяется.
4. **Время — в UTC.** Все даты передаются и возвращаются в UTC.
