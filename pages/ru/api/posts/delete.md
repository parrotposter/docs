# Удаление поста

Мутация `deletePost` удаляет пост. Требуется токен с правом записи и активный тариф. Удалять можно только свои посты.

Пост не стирается сразу: он помечается удалённым и попадает в **Корзину** в кабинете (оттуда его можно вернуть, если он ещё не публиковался, или удалить окончательно; в корзине посты хранятся 30 дней). Для опубликованного поста удаление запускает и удаление публикаций из соцсетей там, где это поддерживается; такой пост восстановить уже нельзя.

```graphql
mutation {
  deletePost(id: "post_id") {
    id
  }
}
```

## Параметры

| Аргумент | Тип | Описание                         |
| -------- | --- | -------------------------------- |
| `id`     | ID! | Идентификатор поста для удаления |

## Ответ

Мутация возвращает `Post`, в котором заполнено только поле `id` — идентификатор удалённого поста. Остальные поля будут пустыми, поэтому запрашивайте только `id`.

В списке постов удалённые посты по умолчанию не показываются; чтобы увидеть корзину, используйте фильтр `deleted: true` ([получение постов](./get.md)).
