# Обновление поста

Мутация `updatePost` меняет существующий пост: ещё не опубликованный, запланированный, черновик или уже опубликованный (с ограничениями ниже). Требуется токен с правом записи и активный тариф.

```graphql
mutation {
  updatePost(
    id: "post_id"
    post: { fields: { text: "Обновлённый текст поста" } }
  ) {
    id
    status
  }
}
```

## Параметры

| Аргумент | Тип         | Описание                                  |
| -------- | ----------- | ----------------------------------------- |
| `id`     | ID!         | Идентификатор поста                       |
| `post`   | PostUpdate! | Изменяемые данные (все поля необязательные) |

Поля `PostUpdate`:

| Поле             | Тип                     | Описание                                                                                                                      |
| ---------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `fields`         | PostFieldsInput         | Содержимое — те же поля, что и в [`createPost`](./create.md)                                                                  |
| `networks`       | PostNetworksInput       | Аккаунты для публикации                                                                                                        |
| `publishAt`      | DateTime                | Новое время публикации (UTC)                                                                                                   |
| `draft`          | Boolean                 | `false` — перевести черновик в публикацию                                                                                      |
| `draftParams`    | DraftParamsInput        | Расписание черновика. Не указан — остаётся прежним. Если переводите черновик в публикацию (`draft: false`), передайте расписание, чтобы оно превратилось в время публикации |
| `fieldOverrides` | PostFieldOverridesInput | Правки для отдельных соцсетей и аккаунтов. Не указан — остаются прежними; пустые `bySocialType` и `byAccount` очищают их      |

В отличие от `createPost`, здесь нет `publishDelayMinutes`: для изменения времени используйте `publishAt`.

## Ответ

Мутация возвращает объект обновлённого поста [`Post`](./item.md).

## Ограничения

- Нельзя обновить опубликованный пост, если с момента публикации прошло больше суток.
- Нельзя менять время публикации (`publishAt`) уже опубликованного поста.
- Пока пост обрабатывается (публикуется или обновляется), обновление отклоняется — повторите запрос позже.
- Изменение изображений и ссылки в уже опубликованном посте поддерживается не всеми соцсетями: в некоторых из них такие правки не применятся. Операции, недоступные для конкретной публикации, перечислены в `results[].notAllowed` (см. [структуру Post](./item.md)).

Коды ошибок описаны в разделе [Ошибки](../errors.md).
