# Введение

GraphQL API ParrotPoster позволяет автоматизировать публикацию постов в социальные сети, управлять постами и получать список подключённых аккаунтов из ваших скриптов, сайтов и сервисов.

## Общие сведения

API построено на **GraphQL**: вы запрашиваете только те поля, которые вам нужны, и получаете их одним запросом. Веб-приложение ParrotPoster и плагины для WordPress и 1C-Битрикс работают через тот же API.

**Адрес API:**

```text:no-line-numbers
https://parrotposter.com/api/graphql
```

- **POST-запрос** выполняет запросы (`query`) и мутации (`mutation`). Тело — JSON с полем `query` (и при необходимости `variables`). Так API нужно вызывать из кода.
- **GET-запрос** открывает в браузере интерактивную среду **GraphiQL** (playground): в ней видна полная схема и можно пробовать запросы вручную.

[Открыть Playground](https://parrotposter.com/api/graphql)

## Что можно делать через API

- получать список подключённых [аккаунтов](./socials.md) и их состояние;
- [создавать](./posts/create.md), [получать](./posts/get.md), [обновлять](./posts/update.md) и [удалять](./posts/delete.md) посты;
- публиковать сразу, по расписанию или сохранять как черновик;
- читать результаты публикации и статистику вовлечённости.

Подключать аккаунты соцсетей и настраивать автоматизацию нужно в [личном кабинете](../accounts/index.md): через API это не делается.

## Как начать

1. В кабинете откройте **Настройки → API-токены** и создайте токен ([подробнее](./auth.md)).
2. Передавайте токен в заголовке `Authorization: Bearer <токен>`.
3. Выполните первый запрос — см. [Начало работы](./quick-start.md).

## Ограничения

- Публикация и изменение постов требуют активного тарифа, а количество постов и аккаунтов ограничено вашим [тарифом](../billing/index.md).
- На запросы по API-токену действует лимит частоты: по умолчанию 600 запросов в минуту на один токен. При превышении сервер отвечает HTTP-статусом `429`. Подробнее — в разделе [Ошибки](./errors.md).

## Совместимость

Схема API расширяется новыми полями и методами. Устаревшие поля помечаются директивой `@deprecated` в схеме (её видно в playground), поэтому запрашивайте только нужные поля и не полагайтесь на порядок полей в ответе.
