# Подключение Facebook

Подключение идёт через официальную авторизацию Facebook. Публиковать можно только на **страницы** Facebook: ни личный профиль, ни группы подключить нельзя.

## Инструкция

1. Откройте раздел **Аккаунты** и нажмите кнопку **Facebook** над списком аккаунтов.

   ![Добавление](/images/socials/fb/fb-0.png)

2. Если у вас уже есть действующее подключение Facebook, ParrotPoster предложит **Использовать** его или создать **Новое подключение**.
3. Facebook попросит подтвердить доступ для ParrotPoster. Нажмите **Продолжить**.

   ![Подтверждение](/images/socials/fb/fb-1.png)

4. Выберите пункт «предоставить доступ ко всем спискам страниц», чтобы в будущем не было проблем с добавлением новых страниц, и нажмите **Продолжить**.

   ![Выбор страниц](/images/socials/fb/fb-2.png)

5. Facebook покажет, какие права получит ParrotPoster. Нажмите **Сохранить**.

   ![Права](/images/socials/fb/fb-3.png)

6. Facebook покажет ссылку на страницу, где можно управлять доступами всех приложений (она также есть в настройках вашего профиля). Нажмите **ОК**.

   ![Готово на стороне Facebook](/images/socials/fb/fb-4.png)

7. На странице «Выберите сообщества для добавления» отметьте нужные страницы Facebook и нажмите **Добавить**.

   ![Выбор страниц](/images/socials/fb/fb-5.png)

Готово: страницы появятся в списке аккаунтов.

## Переподключение

Если у аккаунта появилась ошибка, выберите в меню карточки **Переподключить**: ParrotPoster попробует восстановить доступ автоматически, а при необходимости откроет повторную авторизацию Facebook. Подробнее — в [обзоре аккаунтов](./index.md#переподключение-и-удаление).

## Возможные проблемы

::: details Не отображается список групп
Сейчас к ParrotPoster можно подключать только страницы Facebook, группы не поддерживаются.
:::

::: details Нет возможности выбрать профиль
ParrotPoster не публикует в личный профиль, только на специально созданные для этого страницы.
:::

::: details Пустой список на этапе выбора страниц
Проверьте, что вы администратор или модератор нужной страницы и что на шаге выбора доступов вы разрешили доступ ко всем страницам. Если проблема остаётся, напишите на [support@parrotposter.com](mailto:support@parrotposter.com).
:::
