# Подключение Instagram через Session ID

Этот способ нужен, если при входе по логину и паролю Instagram не присылает SMS или код двухфакторной аутентификации. Вы входите в Instagram в браузере на компьютере (там SMS и 2FA обычно работают), копируете cookie `sessionid` и вставляете его в ParrotPoster. Пароль в ParrotPoster не нужен.

## Как скопировать sessionid

1. Откройте [instagram.com](https://www.instagram.com) в браузере на компьютере и войдите в аккаунт.
2. Откройте инструменты разработчика (клавиша **F12**) и найдите cookie `sessionid` для `https://www.instagram.com`:

   **Chrome, Edge, Яндекс.Браузер** — F12 → вкладка **Application** → слева **Cookies → https://www.instagram.com** → строка **sessionid** → скопируйте **Value**.

   **Firefox** — F12 → вкладка **Storage** → **Cookies → https://www.instagram.com** → **sessionid** → **Value**.

   **Safari (Mac)** — включите меню «Разработка» в настройках Safari → **Разработка → Показать веб-инспектор** → **Хранилище → Cookies** → **sessionid**.

3. Скопируйте именно значение из колонки **Value** — это длинная строка (50+ символов), которая начинается с цифр вашего userId. Не копируйте `ds_user_id` или `csrftoken`.
4. В ParrotPoster откройте **Аккаунты → Instagram**, выберите «Через Session ID (если SMS не приходит)», вставьте значение в поле «Session ID» и нажмите **Подключить**.

::: warning Безопасность
Не передавайте Session ID посторонним: по нему можно войти в ваш аккаунт.
:::

## Срок действия

Session ID действителен около 90 дней. При смене пароля или выходе из аккаунта в браузере потребуется переподключить аккаунт: в меню карточки выберите **Переподключить**, откройте вкладку **Session ID** и вставьте новое значение.

::: tip Прокси
Для Session ID, как и для входа по логину и паролю, доступно поле «Прокси (при необходимости)». Подробнее — в [инструкции по Instagram](./index.md#использование-прокси).
:::

## Возможные проблемы

::: details «Не удалось подключить. Проверьте правильность введённых данных»
- Скопировано значение из колонки **Value** строки `sessionid`, без лишних пробелов и кавычек.
- Не перепутаны строки: `ds_user_id` и `csrftoken` не подходят.
- Вы не вышли из аккаунта в браузере после копирования: при выходе Session ID перестаёт действовать (см. «Срок действия»).
:::

::: details Подключение перестало работать
Скорее всего, прошло около 90 дней, вы сменили пароль или вышли из аккаунта. Скопируйте новый `sessionid` и выполните **Переподключить**.
:::

::: details Не нашёл cookies в инструментах разработчика
Убедитесь, что открыта вкладка **Application** (Chrome, Edge, Яндекс.Браузер) или **Storage** (Firefox) и выбран домен `https://www.instagram.com`. Если вкладки нет, откройте инструменты разработчика на странице instagram.com.
:::
