# Плагин ParrotPoster для WordPress

Плагин подключает ваш сайт на WordPress к ParrotPoster: кабинет сервиса открывается прямо в админке, записи можно публиковать в соцсети в один клик, а правила автопубликации работают в фоне.

[Страница плагина в каталоге WordPress](https://wordpress.org/plugins/parrotposter/)

## Требования

- WordPress 5.3 или новее;
- PHP 7.4 или новее;
- права администратора сайта (для подключения сайта и настроек плагина).

## Установка

1. В админке WordPress откройте **Плагины → Добавить новый плагин**.
2. В поле поиска введите `parrotposter` и найдите плагин «ParrotPoster — Auto Post to Social Media». Нажмите «Установить».

   ![Установка плагина](/images/wp/install.png)

3. Нажмите «Активировать».

   ![Активация плагина](/images/wp/install-2.png)

4. В меню слева появится пункт **ParrotPoster**.

## Первый запуск

1. Откройте **ParrotPoster**. Пока вы не вошли в сервис, плагин показывает экран авторизации (это встроенное окно кабинета):
   - «Начать как анонимный пользователь» — быстрый старт без ввода данных;
   - «Войти через Google»;
   - «Войти через ParrotPoster» — вход по email и паролю, там же можно зарегистрироваться.

   <!-- screenshot: wp-auth | Экран авторизации внутри плагина WordPress (страница ParrotPoster до входа) -->

2. После входа сайт **подключается к ParrotPoster автоматически**. Отдельных действий не требуется.
3. Откройте **ParrotPoster → Настройки** и убедитесь, что в блоке «Интеграция сайта» стоит статус «Подключено».

Новым пользователям доступен бесплатный пробный период 14 дней. Тот же email и пароль подходят для входа в кабинет на [parrotposter.com](https://parrotposter.com).

::: tip Нет страницы «Профиль»
Страницы «Профиль» в плагине нет. Данные учётной записи, тариф и срок его действия смотрите в **ParrotPoster → Настройки**, а имя, пароль и сеансы — в [кабинете](/ru/start/#настройки).
:::

## Меню плагина

| Пункт | Что это |
| ----- | ------- |
| Посты | Ручные посты, черновики, календарь — [Посты](/ru/posts/). Встроенное окно кабинета |
| Автоматизация | Правила автопубликации — [Автоматизация](/ru/automation/). Встроенное окно кабинета. Вместо неё может показываться «Планировщик» — см. [ниже](#какая-схема-автопубликации-у-вас) |
| Аккаунты | Подключение соцсетей — [Аккаунты](/ru/accounts/). Встроенное окно кабинета |
| Тарифы | [Тарифы и оплата](/ru/billing/). Встроенное окно кабинета |
| Настройки | Собственная страница плагина: учётная запись, подключение сайта |
| Помощь | Краткие ответы на частые вопросы |

Меню плагина появляется после входа в сервис. В плагине нет разделов ParrotAI, «Поддержка» и настроек кабинета — они есть в [кабинете](https://parrotposter.com).

## Подключение аккаунтов соцсетей

Откройте **ParrotPoster → Аккаунты** и нажмите «Подключить» у нужной соцсети. Подробные инструкции и особенности — в разделе [Аккаунты](/ru/accounts/): [ВКонтакте](/ru/accounts/vk.md), [Telegram](/ru/accounts/tg.md), [Facebook](/ru/accounts/fb.md), [Instagram](/ru/accounts/insta/), [Одноклассники](/ru/accounts/ok.md), [Дзен](/ru/accounts/dzen.md), [MAX](/ru/accounts/max.md).

## Публикация со страницы записи

Публиковать можно любую уже сохранённую запись (или другой тип записей, с которым работает плагин).

- **В списке записей** в таблице появляется столбец ParrotPoster. Нажмите значок в строке нужной записи.
- **На странице редактирования** справа находится блок ParrotPoster с кнопкой «Опубликовать в социальные сети» и ссылкой «Показать опубликованные в соц. сетях посты» — там видны результаты публикации по каждой соцсети.

Что откроется дальше, зависит от схемы автопубликации сайта:

- **Режим «Автоматизация».** Откроется окно «Опубликовать пост». Если запись уже публиковалась, есть вкладка «В соцсетях» с результатами и ссылками на посты, а вкладка «Опубликовать ещё» позволяет запустить публикацию заново. Выберите автоматизацию («Выберите автоматизацию») и нажмите «Опубликовать». Если подходящих автоматизаций нет, окно предложит «Открыть автоматизацию» — создайте правило, см. [Автоматизация](/ru/automation/).
- **Режим «Планировщик».** Окно предложит опубликовать по ранее созданным [шаблонам](/ru/automation/classic/wordpress.md) либо нажать «Опубликовать вручную» — откроется форма ручного поста.

<!-- screenshot: wp-publish-modal | Окно «Опубликовать пост» на странице редактирования записи WordPress -->

Результат публикации появится в **ParrotPoster → Посты**.

## Подключение сайта и статус

В **ParrotPoster → Настройки** есть три блока:

- **Аккаунт** — имя, email, тариф, срок его действия («Срок действия» с оставшимися днями) и счётчик подключённых аккаунтов. Здесь же кнопка «Открыть веб-приложение» (кабинет в новой вкладке) и «Выйти» из сервиса на этом сайте.
- **Интеграция сайта** — статус «Подключено» или «Не подключено». Для подключённого сайта показано, когда в последний раз были «Запросы с сайта» (WordPress → ParrotPoster) и «Обращения к сайту» (ParrotPoster → WordPress). Если сайт не подключён, нажмите «Подключить сайт».
- **Опасная зона → «Отключить сайт»** — отключает сайт от автоматизации ParrotPoster. Учётная запись остаётся активной. Чтобы подключить сайт снова, нажмите «Подключить сайт» в этом же блоке. После отключения сайта в кабинете на странице «Интеграции» у него будет статус «Отключён» — включить его можно только из плагина.

::: warning Сайт на HTTP
Если сайт работает по HTTP, в блоке «Интеграция сайта» показывается предупреждение: ParrotPoster не обращается к сайту сам, данные обмениваются, когда WordPress опрашивает сервис. Включите HTTPS и затем подключите сайт заново («Подключить сайт»), чтобы сервис запомнил HTTPS-адрес. То же предупреждение появляется, если адрес сайта изменился после подключения (например, смена домена): нажмите «Подключить сайт».
:::

## Какая схема автопубликации у вас

В плагине две схемы автопубликации, и вы всегда видите, какая включена, по пункту меню:

- **«Автоматизация»** — новая схема: те же автоматизации, что в кабинете. Описана в разделе [Автоматизация](/ru/automation/) (в плагине тот же мастер открывается как встроенная страница).
- **«Планировщик»** — классическая схема с шаблонами автопостинга: [Классическая автопубликация для WordPress](/ru/automation/classic/wordpress.md). Вкладка «Автовыгрузка» в нём не используется.

Переключение происходит автоматически при подключении сайта: если у сайта нет включённых шаблонов классического планировщика, плагин переходит на «Автоматизацию». Если шаблоны есть, остаётся «Планировщик», а на его странице предлагается перенести шаблоны в автоматизации или начать с нуля. Если новая схема вам не подошла, вернуться можно кнопкой «Вернуться к планировщику» в **ParrotPoster → Настройки** (блок виден, пока в плагине есть включённые шаблоны планировщика).

## Если что-то не работает

| Симптом | Что сделать |
| ------- | ----------- |
| В «Настройки» статус «Не подключено» | Нажмите «Подключить сайт». Если не помогло — «Выйти» и войдите снова |
| Предупреждение про HTTP или смену адреса сайта | Включите HTTPS и нажмите «Подключить сайт» — см. выше |
| Нет пункта ParrotPoster или в меню нет «Посты» и «Аккаунты» | Вы ещё не вошли в сервис — откройте ParrotPoster и авторизуйтесь |
| Не публикует или не добавляется аккаунт | Проверьте срок тарифа и лимит аккаунтов в **Настройки**; срок и оплата — в [Тарифы и оплата](/ru/billing/) |
| Автоматизация не срабатывает | См. [Диагностика автоматизации](/ru/automation/troubleshooting.md) |
| Ошибка публикации в соцсеть | См. инструкцию по [нужной соцсети](/ru/accounts/) |

Не нашли ответ — напишите на [support@parrotposter.com](mailto:support@parrotposter.com).
