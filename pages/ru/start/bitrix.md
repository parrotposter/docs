# Модуль ParrotPoster для 1С-Битрикс

Модуль `vettich.sp3` («Автопубликации в соц. сети») связывает сайт на «1С-Битрикс: Управление сайтом» с ParrotPoster: аккаунты и посты управляются из админки Битрикс, а материалы из инфоблоков можно публиковать в соцсети автоматически.

## Требования

- PHP 7.4 или новее;
- расширения PHP `curl` и `json` — модуль проверяет их при установке и в админке;
- права на запись к модулю `vettich.sp3` у пользователя, который авторизует модуль (настройки групп пользователей Битрикс).

## Установка

1. Откройте страницу модуля в [маркетплейсе 1С-Битрикс](https://marketplace.1c-bitrix.ru/solutions/vettich.sp3/) и нажмите «Установить». Дальше установка стандартная для Битрикс.

   ![Маркетплейс 1С-Битрикс](/images/bx/install-1.1.png)

2. В админке откройте **Настройки → Настройки продукта → Модули**, найдите модуль «vettich.sp3» («Автопубликация в социальные сети 3») и убедитесь, что он установлен (при необходимости нажмите «Установить»).
3. В меню админки откройте **Сервисы → Автопубликации в соц. сети**.

## Авторизация

Модуль работает на основе облачного сервиса [ParrotPoster](https://parrotposter.com), поэтому в нём нужно авторизоваться или зарегистрироваться.

1. Откройте пункт **Начать** («Начать пользоваться. Вход в сервис»). Он открывает окно авторизации кабинета внутри админки.
2. Войдите или зарегистрируйтесь (email и пароль или другие способы, доступные на экране) и подтвердите согласие с политикой конфиденциальности.

   ![Регистрация в модуле](/images/bx/install-2.1.png)

3. После успешного входа вместо пункта «Начать» в меню появятся остальные разделы модуля.

Новым пользователям доступен бесплатный пробный период 14 дней. Тот же email и пароль подходят для входа в кабинет на [parrotposter.com](https://parrotposter.com).

::: warning Не хватает прав
Если вы видите сообщение о недостатке прав, попросите администратора сайта выдать вашей группе права на запись к модулю `vettich.sp3` (в настройках групп пользователей Битрикс или на вкладке «Доступ» настроек модуля) и повторите вход.
:::

## Меню модуля

Меню находится в **Сервисы → Автопубликации в соц. сети**.

| Пункт | Что это |
| ----- | ------- |
| Начать | Вход и регистрация (виден, пока вы не авторизованы). Встроенное окно кабинета |
| Пользователь | Данные учётной записи: имя, тариф, срок тарифа, использовано аккаунтов, ссылка на список тарифов, кнопка «Выйти» |
| Аккаунты | Подключение соцсетей — [Аккаунты](/ru/accounts/). Встроенное окно кабинета |
| Посты | Создание и список постов — [Посты](/ru/posts/). Встроенное окно кабинета |
| Шаблоны | Классическая автопубликация из инфоблоков — [Классическая автопубликация для 1С-Битрикс](/ru/automation/classic/bitrix.md) |
| Помощь | Краткая справка по модулю |
| Что нового | Список изменений (пункт можно скрыть в настройках модуля) |
| Настройки | Настройки модуля Битрикс (виден пользователям с правом записи) |

![Раздел «Пользователь» в модуле](/images/bx/profile.png)

В модуле нет ParrotAI, раздела «Поддержка» и настроек кабинета — они доступны в [кабинете](https://parrotposter.com) под той же учётной записью.

## Аккаунты

1. Откройте **Аккаунты**. Сразу после регистрации список пуст.

   ![Пустой список аккаунтов](/images/bx/accounts-empty.png)

2. Нажмите «Добавить». В скобках на кнопке указано, сколько аккаунтов подключено и сколько доступно на тарифе.
3. Выберите соцсеть и нажмите «Перейти к добавлению», затем выберите нужную группу или страницу.

   ![Подключение аккаунтов](/images/bx/accounts-connect.png)

Подробности по каждой площадке: [ВКонтакте](/ru/accounts/vk.md), [Telegram](/ru/accounts/tg.md), [Facebook](/ru/accounts/fb.md), [Instagram](/ru/accounts/insta/), [Одноклассники](/ru/accounts/ok.md), [Дзен](/ru/accounts/dzen.md), [MAX](/ru/accounts/max.md).

## Посты

Раздел «Посты» — окно кабинета: создание поста, выбор аккаунтов, настройки соцсетей, отложенная публикация. Инструкции — в разделе [Посты](/ru/posts/).

Если на странице «Посты» показано «В локальной очереди элементов: N» — это временный список заданий на вашем сайте: изменения по элементам инфоблока, которые модуль ещё передаёт в ParrotPoster. Отправка идёт отдельно, в фоне.

## Автоматическая публикация

В модуле используется **классическая автопубликация** через раздел «Шаблоны»: шаблон привязывается к инфоблоку и публикует новые элементы в выбранные аккаунты (аналог режима «Мгновенно»), а также умеет выгружать уже существующие элементы (аналог режима «Архив»). Подробно — [Классическая автопубликация для 1С-Битрикс](/ru/automation/classic/bitrix.md).

::: warning Новая автоматизация в модуле пока недоступна
Раздела «Автоматизация» (пайплайны кабинета) в модуле для 1С-Битрикс нет. Новая автоматизация доступна в [кабинете](/ru/automation/) для RSS-источников и в плагине для WordPress.
:::

## Настройки модуля

**Сервисы → Автопубликации в соц. сети → Настройки** открывает стандартную страницу настроек модуля Битрикс. В ней две вкладки:

- **Настройки** — опция «Показывать пункт "Что нового" в меню модуля»;
- **Доступ** — права групп пользователей на модуль (чтение и запись; для авторизации и настроек нужна запись).

## Агенты и cron

Модулю нужны агенты Битрикс: они передают в ParrotPoster накопленные изменения из локальной очереди и обновляют список доменов. Чтобы агенты выполнялись по расписанию, а не только при заходах на сайт, в `/bitrix/php_interface/dbconn.php` добавьте:

```php
define("BX_CRONTAB_SUPPORT", true);
```

и настройте запуск агентов из cron сервера, как описано в документации 1С-Битрикс для работы агентов на cron.

## Если что-то не работает

| Симптом | Что сделать |
| ------- | ----------- |
| Сообщение про PHP или расширение curl | Обновите PHP до 7.4+ и включите расширение `curl` |
| Меню модуля содержит только «Начать» | Авторизуйтесь в модуле (см. выше) |
| Недостаточно прав | Выдайте группе права на запись к модулю `vettich.sp3` |
| В «Постах» накапливается локальная очередь | Проверьте, что агенты Битрикс выполняются (см. выше) |
| Не публикуется / не добавляется аккаунт | Проверьте тариф и лимит аккаунтов в «Пользователь»; [Тарифы и оплата](/ru/billing/) |

Не нашли ответ — напишите на [support@parrotposter.com](mailto:support@parrotposter.com).
