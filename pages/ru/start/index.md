# Начало работы

## Как это работает

1. **Зарегистрируйтесь** в [личном кабинете](https://parrotposter.com) — или установите [плагин для WordPress](./wordpress.md) / [модуль для 1С-Битрикс](./bitrix.md) и авторизуйтесь в нём: это та же учётная запись.
2. **Подключите аккаунты соцсетей** в разделе «Аккаунты». Инструкции по каждой площадке — в разделе [Аккаунты](/ru/accounts/).
3. **Публикуйте** — вручную ([Посты](/ru/posts/)) или автоматически ([Автоматизация](/ru/automation/)): записи с сайта или из RSS-ленты сами уходят в выбранные соцсети.

Новым пользователям доступен бесплатный пробный период 14 дней.

## Выберите способ работы

| Способ | Подойдёт, если | Инструкция |
| ------ | -------------- | ---------- |
| Личный кабинет | Нужны ручные посты, календарь, автоматизация по RSS; CMS не обязательна | Ниже на этой странице |
| Плагин для WordPress | Сайт на WordPress, нужно публиковать из админки и автоматически | [Плагин для WordPress](./wordpress.md) |
| Модуль для 1С-Битрикс | Сайт на «1С-Битрикс: Управление сайтом» | [Модуль для 1С-Битрикс](./bitrix.md) |
| API | Нужно встроить публикации в свой сервис или скрипт | [API](/ru/api/quick-start.md) |

## Регистрация и вход в кабинете

1. Откройте [parrotposter.com](https://parrotposter.com) и перейдите на страницу входа.
2. Нажмите «Регистрация», укажите имя, email и пароль (не короче 6 символов), отметьте согласие с правилами обработки данных и нажмите «Зарегистрироваться». Либо нажмите «Продолжить с Google» — отдельная регистрация не нужна.
3. Для входа укажите email и пароль и нажмите «Войти» или воспользуйтесь входом через Google.
4. Если забыли пароль, нажмите «Забыли пароль?» — на почту придёт ссылка для сброса.

Одна и та же учётная запись работает в кабинете, плагинах и API.

### Интеграции

Страница «Интеграции» состоит из двух вкладок:

- **Сайты** — сайты, на которых установлен плагин и выполнена авторизация: они подключаются сюда автоматически. Для каждого сайта видны статус («Активен» или «Отключён») и последняя активность: «Запросы с сайта» и «Обращения к сайту». Сайт можно отключить (автопубликация с него остановится, автоматизации не удалятся) или удалить. Включить отключённый сайт обратно можно только из плагина на самом сайте — подробнее в разделе [WordPress](./wordpress.md#подключение-сайта-и-статус). Кнопка «Подключить сайт» открывает подключение нового сайта.
- **AI-модели** — собственные ключи API OpenAI, Anthropic или OpenAI-совместимого провайдера для AI-обработки текстов постов.

### Настройки

Раздел «Настройки» разбит на группы:

- **Аккаунт** — «Профиль» (ваше имя) и «Сменить пароль».
- **Безопасность** — «Сеансы» (активные входы: веб-приложение и плагины на сайтах; чужие сеансы можно завершить) и «API-токены» (токены для скриптов и своих интеграций; секрет показывается только один раз — см. [API: авторизация](/ru/api/auth.md)).
- **Приложение** — «Посты» (минимальный интервал между постами в секундах; на автоматизацию не влияет — там интервал задаётся в правилах публикации) и «Уведомления» (адреса почты и типы писем: системные, новости и акции, ошибки публикации, ответы поддержки).

## Что в плагинах, а что в кабинете

Плагины WordPress и 1С-Битрикс показывают тот же интерфейс, что и кабинет, прямо в админке сайта: страницы «Посты», «Аккаунты», «Тарифы» и (в WordPress) «Автоматизация» — это кабинет во встроенном окне. Поэтому инструкции в этой документации написаны один раз — для кабинета — и подходят для плагинов.

Только в плагинах есть:

- установка, авторизация и подключение сайта к ParrotPoster;
- настройки самого плагина;
- классическая автопубликация — [WordPress](/ru/automation/classic/wordpress.md), [1С-Битрикс](/ru/automation/classic/bitrix.md);
- публикация записи прямо из списка записей и со страницы редактирования (WordPress).

Только в кабинете: ParrotAI, «Поддержка», «Интеграции», «Настройки» кабинета (профиль, сеансы, API-токены, уведомления). Если нужна такая функция — откройте [parrotposter.com](https://parrotposter.com) и войдите под той же учётной записью.
