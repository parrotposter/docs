# Публикация в Дзен

::: tip Как это работает
Дзен не предоставляет открытый API для публикации контента в Дзен сторонними сервисами.
Официальный способ автоматической публикации — через **официальный Telegram-бот Дзен** [`@zen_sync_bot`](https://t.me/zen_sync_bot), который дублирует посты из вашего Telegram-канала в Дзен.

Схема проста: ParrotPoster публикует пост в ваш Telegram-канал → бот автоматически копирует его в Дзен.
:::

::: warning Ограничения

- Обновление и удаление поста в Telegram **не синхронизируются** с Дзеном — правки делаются вручную в кабинете Дзена.
- Канал Telegram должен быть **публичным**.
- Посты с текстом публикуются как **статьи** в Дзене; посты только с фото или видео — как **медиапосты**.
  :::

## Шаг 2. Свяжите Telegram-канал с Дзеном

### 2.1. Получите код доступа в кабинете Дзена

1. Откройте свой канал и перейдите в Настройки канала.
2. В меню слева найдите раздел **Настройки** → **Кросспостинг** → **Telegram-бот**.
3. Нажмите **Получить код доступа**.

![Настройки](/images/socials/dzen/dzen-settings.png)

Код будет длинной комбинацией букв и цифр. **Скопируйте его** — он действует **30 минут**, после чего нужно будет генерировать новый.

![Код доступа](/images/socials/dzen/dzen-settings-code.png)

### 2.2. Привяжите канал через Синхробот Дзена

1. Откройте Telegram и найдите бота **[@zen_sync_bot](https://t.me/zen_sync_bot)** («Синхробот Дзена»).
2. Нажмите **Запустить** (или `/start`).

![Запуск бота](/images/socials/dzen/dzen-bot-start.png)

3. **Вставьте скопированный код** в диалог с ботом. Бот подтвердит привязку к вашему каналу в Дзене и спросит о согласии.
4. Подтвердите.

![Подключение канала Дзен](/images/socials/dzen/dzen-bot-ready.png)

5. Введите команду `/sync`.

![Начало синхронизации](/images/socials/dzen/dzen-bot-sync.png)

### 2.3. Добавьте Синхробота в администраторы Telegram-канала

Бот попросит вас добавить его в администраторы вашего Telegram-канала.

1. Перейдите в ваш Telegram-канал и откройте его настройки.
2. Перейдите в раздел **Администраторы** → **Добавить администратора**.
3. В поиске найдите **@zen_sync_bot** и выберите его.
4. Подтвердите добавление (достаточно оставить разрешение **Публикация сообщений**).

![Добавление бота в администраторы](/images/socials/dzen/dzen-bot-channel-admin.png)

### 2.4. Отправьте ссылку на канал боту

1. Вернитесь в диалог с ботом **@zen_sync_bot**.
2. Скопируйте ссылку на ваш Telegram-канал (вида `https://t.me/имя_канала`) и отправьте её боту.

![Ссылка на канал](/images/socials/dzen/dzen-bot-add-link.png)

3. Выберите режим публикации: **автоматически** (все посты из канала сразу дублируются в Дзен) или **вручную** (пересылаете нужный пост в чат с ботом — он появится в Дзене).

::: tip Рекомендуем «автоматически»
При использовании ParrotPoster удобнее выбрать автоматический режим — тогда каждый пост, отправленный через ParrotPoster в Telegram-канал, будет появляться в Дзене без дополнительных действий.
:::

![Автоматическая публикация](/images/socials/dzen/dzen-bot-auto.png)

## Шаг 3. Проверьте работу

1. В **ParrotPoster** создайте тестовый пост и выберите ваш Telegram-канал в качестве аккаунта для публикации.
2. После публикации перейдите в ваш Telegram-канал — пост должен появиться.
3. Через 2–5 минут откройте ваш канал в Дзене — пост должен появиться и там.

## Что происходит с длинными постами

| Длина текста в Telegram            | Формат в Дзене                                    |
| ---------------------------------- | ------------------------------------------------- |
| До 1 500 символов                  | **Пост**                                          |
| От 1 500 до 3 000 символов         | **Статья** или несколько постов (определяет Дзен) |
| Без текста (только фото или видео) | **Медиапост**                                     |

## Часто задаваемые вопросы

::: details Можно ли подключить несколько каналов Дзена?
Да. Каждый Telegram-канал нужно отдельно связать с отдельным каналом Дзена через бота — создайте отдельный аккаунт в ParrotPoster для каждого TG-канала.
:::

::: details Я отредактировал/удалил пост в Telegram — изменится ли он в Дзене?
Нет. Редактирование и удаление постов в Telegram **не синхронизируются** с Дзеном. Чтобы изменить уже опубликованный в Дзене материал, войдите в [Студию Дзена](https://dzen.ru/profile/editor) и отредактируйте его вручную.
:::

::: details Пост опубликован в Telegram, но в Дзене не появился
Подождите 5–10 минут — иногда синхронизация занимает чуть больше времени. Если пост так и не появился:

- Проверьте, что [@zen_sync_bot](https://t.me/zen_sync_bot) всё ещё является администратором вашего Telegram-канала.
- Проверьте, что Telegram-канал публичный.

:::

::: details Можно ли опубликовать отдельный пост только в Дзене, минуя Telegram?
Нет — такой возможности нет. Дзен получает посты только из Telegram-канала через Синхробот.
:::
