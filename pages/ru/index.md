# ParrotPoster — автопостинг в социальные сети

**ParrotPoster** — облачный сервис для публикации контента в социальные сети: вручную из личного кабинета, автоматически с вашего сайта или RSS-ленты, а также по API. Один раз подключили аккаунты — дальше посты уходят в выбранные площадки без ручного копирования в каждую соцсеть.

## Четыре способа пользоваться сервисом

| Способ | Для кого | С чего начать |
| ------ | -------- | ------------- |
| **Личный кабинет** [parrotposter.com](https://parrotposter.com) | Публикации и автоматизация без CMS | [Начало работы](/ru/start/) |
| **Плагин для WordPress** | Сайты на WordPress: кабинет работает прямо в админке | [Плагин для WordPress](/ru/start/wordpress.md) |
| **Модуль для 1С-Битрикс** | Сайты на «1С-Битрикс: Управление сайтом» | [Модуль для 1С-Битрикс](/ru/start/bitrix.md) |
| **GraphQL API и API-токены** | Свои скрипты, сервисы и интеграции | [API](/ru/api/) |

Во всех способах используется одна и та же учётная запись и одни и те же подключённые аккаунты соцсетей.

## Возможности

- **Ручные посты** — текст и медиа, несколько соцсетей сразу, отложенная публикация, черновики и календарь. [Подробнее](/ru/posts/)
- **Автоматизация** — правила, по которым записи с сайта или из RSS/Atom-ленты сами уходят в соцсети: мгновенно, из архива и другими режимами. [Подробнее](/ru/automation/)
- **Настройки под каждую соцсеть** — у каждой площадки свои параметры публикации. [Подробнее](/ru/posts/network-settings.md)
- **Статистика вовлечённости** — показатели вовлечённости опубликованных постов. [Подробнее](/ru/posts/engagement.md)
- **ParrotAI** — встроенный ассистент: отвечает на вопросы по сервису и помогает с настройкой. [Подробнее](/ru/assistant/)
- **GraphQL API и API-токены** — публикации и управление аккаунтами из вашего кода. [Подробнее](/ru/api/)
