# Сервис автопубликаций в соцсети ParrotPoster

**ParrotPoster** — облачный сервис для публикации контента в социальные сети с вашего сайта, из личного кабинета или по API. Идея простая: один раз подключили аккаунты и плагин (или API), дальше новости и посты с сайта уходят в выбранные площадки без ручного копирования в каждую соцсеть.

## Возможности

- **Автопостинг** — публикация материалов с CMS в подключённые аккаунты согласно настройкам.
- **Несколько площадок** — одна публикация может дублироваться в сразу несколько соцсетей.
- **Веб-интерфейс** [parrotposter.com](https://parrotposter.com) — регистрация, профиль, подключение аккаунтов, тот же логин, что и у плагинов; есть триал для знакомства с сервисом.
- **GraphQL API** — встраивание публикаций и управления аккаунтами в свои сценарии и приложения ([документация API](/ru/api/)).

## Плагины и интеграции

| Канал | Описание |
| -------- | -------- |
| [Плагин для WordPress](/ru/wordpress/) | Публикация из админки WordPress, установка из каталога плагинов. |
| [Модуль для 1С-Битрикс](/ru/bitrix/) | Интеграция с «1С-Битрикс: Управление сайтом», установка с маркетплейса. |

Оба варианта работают с тем же облачным бэкендом: авторизация в плагине/модуле — это учётная запись ParrotPoster, дальше настраиваете аккаунты соцсетей и публикации из привычной среды CMS.

## Социальные сети

Поддерживаются, в частности, следующие площадки (детальные инструкции по подключению — в соответствующих разделах):

[ВКонтакте](/ru/socials/vk/) · [Telegram](/ru/socials/tg/) · [Facebook](/ru/socials/fb/) · [Instagram](/ru/socials/insta/) · [Одноклассники](/ru/socials/ok/) · [Дзен](/ru/socials/dzen/) · [MAX](/ru/socials/max/)

Нюансы по каждой площадке (роли, страницы, каналы, боты) описаны в отдельных статьях раздела.
