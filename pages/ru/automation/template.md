# Шаблон публикации

Шаблон описывает, как запись источника превращается в пост: текст, картинки и видео, ссылка, особые параметры каждой соцсети и (по желанию) AI-обработка. Он настраивается на последнем шаге мастера — **Шаблон публикации**, а потом правится в готовой автоматизации на вкладке **Контент** ([как](./edit.md#контент)).

Экран делится на две части: слева редактор, справа **Предпросмотр** выбранных сетей.

## Текст поста

Поле **Текст поста** собирается из обычного текста и подставляемых полей записи (заголовок, анонс, ссылка, рубрики и т.д.).

### Визуальный режим

По умолчанию редактор визуальный: поля источника вставляются как «чипы» внутри текста.

- **Вставить поле** — откроется список полей источника с поиском по названию или ключу. Поля, которые уже есть в шаблоне, помечены **Уже в шаблоне**. Набор полей зависит от источника (для сайта WordPress это, например, основные поля, медиа, рубрики и поля WooCommerce).
- Нажмите на вставленное поле, чтобы открыть **Настройки поля**.
- **Пресеты** — готовые заготовки текста, например **Заголовок + анонс**, **Короткий тизер**, **Товар WooCommerce**. Под дайджест — **Только заголовки**, **Заголовки со ссылками**, **Заголовок + анонс по записи**.

В **Настройках поля** можно:

| Параметр | Что делает |
| --- | --- |
| **Убрать HTML** | Убирает разметку |
| **Только первый абзац** | Берёт первый абзац |
| **Как хештеги** и **Макс. хештегов** | Превращает значение (например, рубрики) в хештеги |
| **Обрезать по символам** / **Обрезать по словам** | Ограничивает длину |
| **Значение по умолчанию, если пусто** | Подстановка (**Подстановка**), если поле пустое |
| **AI-обработка** | Обработка именно этого фрагмента нейросетью, см. [ниже](#ai-обработка) |

Порядок важен: **Убрать HTML** ставьте до AI (модель не должна видеть разметку), а **Обрезать по символам** — после AI как страховку по длине.

Если название поля не найдено в источнике, редактор покажет **Неизвестное поле**. Пока в шаблоне нет текста, сохранить его нельзя.

### Режим Liquid

Переключатель **Режим редактора**: **Визуальный** / **Liquid**. В режиме **Liquid** шаблон — это текст на языке шаблонов Liquid, например:

```liquid
{{ item.title }}

{{ item.title | truncate: 100 }}
```

Фильтры, которые визуальный редактор показывает как настройки поля: `strip_html`, `hashtags`, `truncate`, `truncatewords`, `ai`. Прочие конструкции Liquid остаются в тексте как есть и показываются как неизменяемые вставки. Если шаблон содержит сложные конструкции, редактор открывается в текстовом режиме и предлагает **Переключить на визуальный редактор**.

## Медиа

Блок **Медиа**:

- Включите **Добавить медиа из статьи**.
- В поле **Поле медиа** выберите поле источника с изображением. Кнопкой **+ Добавить поле** можно указать несколько полей — медиа берутся из всех выбранных по порядку (изображения, видео, GIF, аудио, файлы).
- Для **Instagram медиа обязательно**: пост без картинки или видео не выйдет.

Лимиты и поддерживаемые типы вложений у каждой сети свои, и ParrotPoster подгоняет под них пост автоматически. В предпросмотре вы увидите предупреждения, например **Текст обрезан под лимит платформы**, **Список медиа обрезан под лимит платформы**, **Неподдерживаемый тип медиа пропущен**, а для Facebook — что при видео фото будут пропущены (одно видео на пост).

## Ссылка

Блок **Ссылка во вложении**: включите **Добавить ссылку на статью** и выберите **Поле ссылки**. Как именно ссылка попадёт в пост, зависит от сети: в Telegram она показывается как **Ссылка → превью**, в остальных сетях — как **Ссылка → вложение**.

В **Дополнительно: превью ссылки и UTM** можно задать **Заголовок**, **Описание** и **Изображение** карточки ссылки и включить **Добавить UTM-метки**.

## Настройки для отдельных сетей

Вверху редактора есть вкладки: **Общий** и по одной на каждый выбранный на шаге **Аккаунты** тип сети. Если аккаунты ещё не выбраны, вкладок нет — выберите аккаунты, чтобы настроить шаблон под сети.

На вкладке сети любой блок (текст, медиа, ссылка) можно переопределить:

- у блока метка **Как в общем** (используется общий шаблон) или **Переопределено**;
- **Настроить отдельно** — задать свой вариант для этой сети;
- **Вернуть общий** — вернуться к общему;
- **Сбросить все переопределения** — убрать все отличия сразу.

У вкладки, где есть отличия, появляется пометка **Есть переопределения**.

### Параметры публикации по сетям

На вкладках отдельных сетей в блоке **Параметры публикации** есть опции, специфичные для сети.

**Telegram**

| Параметр | Описание |
| --- | --- |
| **Превью ссылки в Telegram** | Для постов без медиа: карточка сайта. URL в текст не дописывается |
| **Крупное превью** | Увеличить медиа в карточке ссылки |
| **Превью над текстом** | Показать карточку ссылки выше текста |
| **Кнопка со ссылкой** и **Текст кнопки** | Кнопка под постом (по умолчанию текст **Читать**) |
| **Без уведомлений** | Отправить без звукового уведомления подписчикам |
| **Защитить контент** | Запретить пересылку и сохранение |
| **Спойлер на медиа** | Скрыть фото, видео или GIF под спойлером (не для аудио и документов) |
| **Подпись над медиа** | Показать подпись выше фото, видео или GIF |

**ВКонтакте**

| Параметр | Описание |
| --- | --- |
| **Публиковать от имени сообщества** | Пост от имени группы, а не пользователя |
| **Добавить подпись к посту** | Показать подпись автора рядом с постом от имени сообщества |
| **Закрыть комментарии** | Отключить комментирование |
| **Без уведомлений** | Не уведомлять подписчиков о новой записи |
| **Отметить как рекламу** | Добавить отметку «Это реклама» к посту от имени сообщества |
| **Отображение медиа** | **Карусель** или **Сетка** — как показать несколько фото или видео |
| **Первый комментарий** и **Текст первого комментария** | После публикации добавить комментарий от имени сообщества (призыв, ссылка, вопрос) |

**Facebook**

| Параметр | Описание |
| --- | --- |
| **Первый комментарий** и **Текст первого комментария** | После публикации добавить комментарий от имени страницы (часто — ссылка на статью, если в посте есть фото) |
| **Кнопка CTA на ссылке** и **Тип кнопки** | Только для постов без медиа: кнопка на карточке ссылки. Типы: **Узнать больше**, **Купить**, **Зарегистрироваться**, **Забронировать**, **Связаться**, **Получить предложение**, **Подписаться**. Если в посте есть фото или видео, кнопка с ссылкой не поддерживается |

**MAX**

| Параметр | Описание |
| --- | --- |
| **Превью ссылки в MAX** | Для постов без фото: карточка сайта. При фото превью отключается автоматически |
| **Кнопка со ссылкой** и **Текст кнопки** | Кнопка под постом (по умолчанию **Читать**) |
| **Без уведомлений** | Не уведомлять участников чата |
| **Первый комментарий (reply)** и **Текст первого комментария** | После публикации отправить ответное сообщение |

Для остальных сетей отдельных параметров в шаблоне нет.

## Предпросмотр

Справа показано, как пост будет выглядеть в каждой выбранной сети: текст, **Медиа: N** и предупреждения по ограничениям сети. Выбрать, на какой записи смотреть, можно в поле **Пример записи** (берутся свежие записи источника, подходящие под отбор). Если записей нет или их не удалось загрузить, кнопка **Показать демо-данные** покажет пример.

До сохранения предпросмотр приблизительный (**Приблизительно — сохраните шаблон для точного превью**). После сохранения он точнее, а ошибки рендеринга показываются в виде **Ошибка превью**.

## AI-обработка

AI может адаптировать готовый текст перед публикацией. Есть два способа, их можно сочетать.

### AI-постобработка всего текста

Блок **AI-постобработка** переключается **Выкл** / **AI**. Её можно включить для всех сетей на вкладке **Общий** и по-разному для разных сетей на вкладках сетей (у вкладки пометка **Свои инструкции** или **Общие инструкции**).

- **Модель**: **Модель по умолчанию** (ParrotPoster, зависит от тарифа) или **Своя модель** (ваш ключ OpenAI, Anthropic или совместимого провайдера; добавляется в разделе **Интеграции → AI-модели**, в поле **Ваша модель** нужно выбрать её).
- **Инструкции**: текст-задание для модели; можно выбрать готовый **Шаблон инструкций** или **Свой промпт**. В инструкции доступны переменные: `{{ platform.type }}`, `{{ platform.name }}`, `{{ platform.max_text_chars }}`, `{{ pipeline.name }}`, `{{ item.* }}`.
- **Температура**: меньшее значение — более стабильный результат.

Кнопка **Прогнать через AI** в предпросмотре запускает настоящую AI-обработку для проверки (расходует ваш лимит AI и может занять до 20 секунд; для этого шаблон должен быть сохранён).

### AI на отдельном фрагменте

В **Настройках поля** включите **AI-обработка**, задайте **Инструкцию** (например, «сократи до трёх предложений, сохрани цифры») и при необходимости **Макс. символов**. В шаблоне действует лимит на число AI-фрагментов, редактор показывает, сколько использовано; лишние фрагменты остаются необработанными. Если AI-фрагмент находится внутри списка записей дайджеста, он выполняется для каждой записи и быстро расходует лимит. Если одновременно включена AI-постобработка всего текста, такие фрагменты обработаются дважды — редактор предупредит.

### Если AI недоступен

AI не блокирует публикацию. Если нейросеть недоступна (неверный ключ, исчерпана квота, модель по умолчанию не входит в тариф, сбой провайдера), пост выйдет с **исходным текстом**, а в журнале на шаге AI-обработки будет пометка **AI недоступен — использован исходный текст**. Это деградация, а не ошибка. Шаблон с AI можно сохранить на любом тарифе: доступность проверяется в момент публикации. Сколько AI доступно, зависит от [тарифа](/ru/billing/index.md).

## Дайджест

Для режима **Дайджест** редактор дополняется блоками:

- **Вставить список записей** — вставляет цикл по записям выпуска. Выберите поля, которые нужны для каждой записи, при необходимости измените **Имя переменной цикла** и нажмите **Вставить**. Вставленный блок затем можно править как обычный текст. Поля вне блока (например, `item.title`) относятся только к самой свежей записи и не повторяются.
- **Вставить число записей** — вставляет количество записей в выпуске.
- **Обложка рубрики** — постоянное изображение, которое показывается первым в каждом выпуске (в отличие от картинки записи, которая меняется). **Загрузить изображение** / **Убрать обложку**.
- **По картинке на запись (карусель)** — по одному изображению от каждой записи; поле изображения выбирается в **Поле изображения**. Число картинок ограничено лимитом сети.
- Предпросмотр строится по нескольким свежим записям (**Пример по N записям**).
