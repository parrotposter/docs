# Автоматизация публикаций

Автоматизация — это правило: **что** публиковать (записи сайта или RSS-ленты), **куда** (ваши аккаунты) и **когда**. Вы настраиваете его один раз, дальше посты уходят в соцсети сами.

В ParrotPoster есть две схемы автопостинга. Выберите свою.

| | Новая автоматизация | Классический автопостинг в плагине |
| --- | --- | --- |
| Где настраивается | Кабинет → **Автоматизация** (в плагине WordPress тот же экран открывается в разделе **Автоматизация**) | Только внутри плагина: **Планировщик** в WordPress, **Шаблоны** в 1С-Битрикс |
| Источник | Сайт на WordPress с плагином версии 2.0 или новее либо RSS/Atom-лента | Сам сайт, на котором стоит плагин |
| Режимы | Мгновенно, Архив, Гибрид, Дайджест | Автопостинг новых записей; в 1С-Битрикс ещё и автовыгрузка |
| Возможности новой схемы | Правила публикации (часовой пояс, допустимые часы, интервал), Liquid-шаблоны, AI-обработка, журнал запусков по шагам | Описаны на страницах классического режима |
| Подходит для | Новых проектов | Сайтов, которые пока остаются на старом режиме плагина |

## Соответствие классического режима новому

| Классический режим | Аналог в новой автоматизации |
| --- | --- |
| WordPress → Планировщик, автопостинг | **Мгновенно** |
| 1С-Битрикс → Шаблоны, автопостинг | **Мгновенно** |
| 1С-Битрикс → Шаблоны, автовыгрузка | **Архив** |

Для WordPress новая автоматизация доступна с версии плагина 2.0. Для 1С-Битрикс новой автоматизации пока нет: работает классический режим. Подробнее:

- [Классический автопостинг WordPress](./classic/wordpress.md)
- [Классический автопостинг 1С-Битрикс](./classic/bitrix.md)

::: tip
Ручные посты никуда не деваются: их по-прежнему создают в разделе **Посты**. Автоматизация нужна для постоянного потока с сайта или из ленты.
:::

## Перед началом

Без этого мастер не даст сохранить правило.

1. **Источник контента** — одно из двух:
   - **сайт на WordPress**: установите [плагин](/ru/start/wordpress.md) версии 2.0 или новее и войдите в него тем же аккаунтом ParrotPoster. Сайт появится в разделе **Интеграции** кабинета;
   - **RSS/Atom-лента**: нужен только её HTTPS-адрес, плагин не требуется. Подробности — на странице [RSS-лента как источник](./rss.md).
2. **Аккаунты соцсетей.** Подключите площадки в разделе **Аккаунты**: [подключение аккаунтов](/ru/accounts/index.md).

## Как выбрать режим

| Хотите… | Режим | Дальше |
| --- | --- | --- |
| Чтобы новые записи сразу уходили в соцсети | **Мгновенно** | [Быстрый старт](./quick-start.md) |
| Постепенно выложить материалы, которые уже есть | **Архив** | [Режимы](./modes.md#архив) |
| И новые записи сразу, и архив по расписанию | **Гибрид** | [Режимы](./modes.md#гибрид) |
| Собирать несколько записей в один пост (раз в день или неделю) | **Дайджест** | [Режимы](./modes.md#дайджест) |

Для RSS-ленты доступен только режим **Мгновенно**. Не уверены — начните с него: это самый короткий путь.

## С чего начать

1. Откройте [кабинет](https://parrotposter.com) → **Автоматизация**.
2. Пройдите [быстрый старт](./quick-start.md).
3. Настройте текст постов: [шаблон](./template.md).
4. Когда правило заработает, смотрите [что делать после настройки](./edit.md): журнал, ручной запуск, выключение.
5. Если что-то не публикуется — [возможные проблемы](./troubleshooting.md).
