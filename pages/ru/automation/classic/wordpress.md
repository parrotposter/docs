# Классический автопостинг в WordPress

Классический **Планировщик** — это прежняя схема плагина ParrotPoster для WordPress: вы создаёте шаблоны автопубликации, и каждая новая запись сайта автоматически уходит в выбранные соцсети. По смыслу это аналог режима «Мгновенно» из [новой автоматизации](/ru/automation/). Публикации по расписанию и выгрузки архива в Планировщике нет.

::: tip Новая схема лучше
Для сайтов с плагином версии 2.0 и выше доступна [новая автоматизация](/ru/automation/): режимы «Мгновенно», «Архив», «Гибрид» и «Дайджест», отбор записей, расписание и журнал запусков. Как перейти — в разделе [Переход на новую автоматизацию](#переход-на-новую-автоматизацию).
:::

## Какая схема включена на сайте

Посмотрите на меню ParrotPoster в админке WordPress:

| Пункт меню | Схема |
| --- | --- |
| **Планировщик** | классическая: шаблоны автопубликации (эта страница) |
| **Автоматизация** | новая: автоматизации ([описание](/ru/automation/)) |

Одновременно работает только одна схема. Пока включена новая, шаблоны Планировщика не срабатывают.

## Что делает автопостинг

- Публикация запускается, когда запись **переходит в статус «Опубликовано»** (например, вы нажали «Опубликовать» или запланированная запись вышла по расписанию WordPress). Запись, которая уже была опубликована, повторно по этому событию не отправляется.
- Автопостинг работает для публичных типов записей (записи, страницы, товары WooCommerce и другие публичные типы).
- Для записи берутся все **включённые** шаблоны её типа, у которых выбран хотя бы один аккаунт и выполнены все условия. По каждому подходящему шаблону создаётся отдельный пост в ParrotPoster — его статус виден в разделе **Посты**.
- Если у шаблона включена опция «Исключать дубликаты», та же запись через этот шаблон повторно не публикуется.
- Если вы **изменили** уже опубликованную запись, текст, теги, ссылка и картинки в связанных постах ParrotPoster обновляются. Это работает, пока пост в ParrotPoster ещё не вышел или с момента его публикации прошло не больше суток; более старые посты не меняются.
- Если запись **удалена или перемещена в корзину**, связанные с ней посты ParrotPoster удаляются.
- Отправка в ParrotPoster идёт через локальную очередь сайта. Если очередь не успела обработаться, вверху страниц плагина появится уведомление об ожидающих элементах с кнопкой просмотра.

## Создать шаблон автопубликации

1. Откройте **ParrotPoster → Планировщик** (вкладка автопостинга открыта по умолчанию).
2. Нажмите **+ Добавить автопостинг**.
3. Заполните форму (поля описаны ниже) и нажмите **Создать**.

Новый шаблон заполнен значениями по умолчанию: тип поста — «Записи», текст — заголовок и отрывок записи, ссылка — на запись, теги — метки записи, картинки — изображения из контента, исключение дубликатов включено. Остаётся выбрать соцсети.

### Общие

| Поле | Что делает |
| --- | --- |
| **Название** | Название шаблона — только для вас. |
| **Выкл/Вкл** | Включает или выключает шаблон. |

### Условия активации

| Поле | Что делает |
| --- | --- |
| **Тип поста Wordpress** | Для каких записей работает шаблон. После смены типа нажмите кнопку **Перезагрузить**: поля формы обновятся под выбранный тип. |
| **Кастомные условия** | Дополнительные ограничения. Кнопка **+ Добавить поле** добавляет условие; пост публикуется, только если выполнены **все** условия. |

Условия, которые можно добавить:

- **Заголовок**: «Включает» или «Не включает» заданный текст.
- **Автор**: «Равно одному из» или «Не равно одному из» выбранных авторов.
- **Рубрики, метки и другие таксономии** выбранного типа поста: «Равно одному из» или «Не равно одному из» выбранных терминов.
- Для товаров WooCommerce: **базовая цена**, **цена распродажи** (а также их минимальные и максимальные значения) — «Равно», «Не равно», «Меньше», «Меньше или равно», «Больше», «Больше или равно»; **тип товара** — «Равно одному из» или «Не равно одному из».

### Шаблон поста

| Поле | Что делает |
| --- | --- |
| **Текст поста** | Текст публикации. Подставляйте данные записи макросами (список ниже). Переносы строк в самом поле не учитываются — для переноса используйте макрос `{br}`. |
| **Ссылка** | Ссылка на запись или товар (по умолчанию `{link}`). Уберите макрос, если ссылка не нужна. |
| **UTM теги** | Если включено, к ссылке добавляются UTM-метки для аналитики. Появляются поля «Источник трафика» (`utm_source`), «Тип трафика» (`utm_medium`), «Название кампании» (`utm_campaign`), «Ключевые слова» (`utm_term`), «Тип контента» (`utm_content`). В полях работают макросы; в источнике трафика макрос `{social_code}` заменяется кодом соцсети (telegram, facebook и т. д.). |
| **Теги** | Теги записи превращаются в хэштеги в конце поста: «красная книга, бестселлер» → `#красная #книга #бестселлер`. По умолчанию `{post_tag}`. |
| **Изображения** | Поля записи, откуда брать картинки. Можно добавить несколько полей кнопкой **+ Добавить поле**. Для Instagram картинка обязательна. |

Требования к картинкам: формат jpg, png или webp, до 10 МБ каждая, не больше 10 в посте. В Facebook загружается только первая картинка из списка.

### Макросы

Список макросов для текста, ссылки, тегов и UTM показан справа от поля «Текст поста»: нажмите на макрос, чтобы вставить его. Набор зависит от типа поста.

| Макрос | Значение |
| --- | --- |
| `{br}` | Перевод строки |
| `{title}` | Заголовок |
| `{content}` | Контент |
| `{content_first_paragraph}` | Первый абзац текста |
| `{excerpt}` | Отрывок |
| `{link}` | Ссылка на запись |
| `{date}` | Дата |
| `{post_tag}`, `{category}` и т. п. | Термины таксономий выбранного типа поста (`{название_таксономии}`) |

Для поля «Изображения» доступны: `{featured_image}` (изображение поста), `{images_in_content}` (изображения из контента), `{featured_video}`, `{videos_in_content}`, `{attached_videos}`, `{gifs_in_content}`, `{attached_audio}`, `{attached_documents}`.

Для товаров WooCommerce добавляются: `{product_title}`, `{product_short_description}`, `{product_description}`, `{product_regular_price}`, `{product_sale_price}`, `{product_currency}`, `{product_height}`, `{product_length}`, `{product_width}`, `{product_weight}`, `{product_link}`, `{product_image}`, `{product_gallery}`.

::: tip
В тексте работают и шорткоды WordPress — они выполняются перед отправкой.
:::

### Выбор соцсетей

В блоке **Выберите социальные сети** отметьте аккаунты, куда публиковать. Подключить аккаунты можно в разделе **Аккаунты** — см. [Аккаунты](/ru/accounts/). Если не выбрано ни одного, шаблон не срабатывает.

### Когда публиковать

| Вариант | Что происходит |
| --- | --- |
| **Сразу после публикации поста** | Пост в соцсетях выходит одновременно с записью на сайте. |
| **С задержкой** | Пост выходит через заданное число минут — от 1 до 10. |

### Дополнительные настройки

- **Исключать дубликаты (в рамках данного шаблона)** — одна и та же запись не публикуется повторно через этот шаблон. Если выключить, одну запись можно опубликовать несколько раз.

### Дополнительные настройки для ВКонтакте

- **Опубликовать пост от имени группы**.
- **Добавить подпись к посту**.

Эти опции применяются только к публикациям во ВКонтакте. Подробнее об аккаунте — [ВКонтакте](/ru/accounts/vk.md).

## Изменить, включить, удалить

В списке шаблонов (**Планировщик**) показаны название, тип поста, время публикации, соцсети и переключатель включения.

- **Редактировать** — нажмите на название или на ссылку «Редактировать», измените поля и нажмите **Обновить**. Изменения касаются только новых публикаций.
- **Включить/выключить** — переключатель в колонке «Выкл/Вкл». Выключенный шаблон не срабатывает.
- **Удалить** — ссылка «Удалить» под названием шаблона.

## Опубликовать запись вручную через шаблон

Запись можно отправить в соцсети в любой момент, не дожидаясь автоматики.

1. Откройте запись в редакторе WordPress.
2. В блоке ParrotPoster нажмите **Опубликовать в социальные сети**.
3. В окне «Опубликовать пост» выберите один или несколько уже созданных шаблонов подходящего типа поста. Если запись через шаблон уже публиковалась, под ним будет предупреждение с датой.
4. Нажмите **Опубликовать через выбранные шаблоны**. Появится сообщение, что пост создан в ParrotPoster; статус смотрите в разделе **Посты**.

Если шаблонов нет или нужны другие настройки, нажмите **Опубликовать вручную** — откроется обычное создание поста, см. [Создание поста](/ru/posts/create.md).

Когда на сайте включена новая автоматизация, то же окно показывает вкладки «В соцсетях» и «Опубликовать ещё» и предлагает публиковать через автоматизации.

## Автовыгрузка

Вкладка **Автовыгрузка** в Планировщике WordPress сейчас недоступна — в ней показано «Этот раздел находится в разработке». Для выгрузки архива записей используйте [новую автоматизацию](/ru/automation/modes.md) в режиме «Архив».

## Переход на новую автоматизацию

Пока на сайте включена классическая схема, вверху Планировщика показан блок **Перейти на Pipelines** («Pipelines» — внутреннее название новой автоматизации). В нём два пути:

- **Перенести выбранные шаблоны** — включённые шаблоны Планировщика преобразуются в автоматизации. В списке под блоком отмечены шаблоны (или их группы); снимите галочки с тех, которые переносить не нужно.
- **Начать с нуля** — переключить сайт на новую схему без переноса. Если шаблонов нет, кнопка называется **Перейти на Pipelines**.

После успешного переключения меню вместо «Планировщик» покажет **Автоматизация**, и откроется её страница.

### Что переносится

Из каждого шаблона переносятся: тип записи, аккаунты, текст (макросы заменяются на аналоги новой схемы), ссылка, картинки, UTM-метки, опции ВКонтакте («от имени группы», «подпись»), условия и задержка публикации (минуты превращаются в паузу перед публикацией).

Условие, которое не удалось преобразовать, пропускается; предупреждения о таких случаях возвращает сервер. После переноса проверьте тексты, UTM и условия в новых автоматизациях.

### Как шаблоны объединяются

Шаблоны, которые различаются только набором аккаунтов (тот же тип записи, условия, время публикации, картинки и текст), объединяются в одну автоматизацию с общим списком аккаунтов. Шаблоны с теми же типом записи, условиями, временем и картинками, но разным текстом и **разными соцсетями** тоже объединяются: для каждой соцсети сохраняется свой вариант текста. В остальных случаях шаблон превращается в отдельную автоматизацию. Название объединённой автоматизации — названия исходных шаблонов через « · ».

### Можно ли вернуться

Да. Пока в новой схеме у вас остаются включённые шаблоны Планировщика, в разделе **Настройки → Pipelines** есть кнопка **Вернуться к планировщику**, а на странице автоматизации — компактный блок «Режим Pipeline активен» с такой же кнопкой (блок можно скрыть; вернуть его показ — флажок «Показывать уведомление о миграции на странице Pipelines» в настройках). После подтверждения сайт снова работает по классической схеме. Созданные автоматизации остаются на сервере, но их срабатывание отключается; шаблоны Планировщика на сайте никуда не исчезают.

::: warning
Кнопка возврата показывается, только пока на сайте есть включённые шаблоны Планировщика. Активна всегда только одна схема.
:::
