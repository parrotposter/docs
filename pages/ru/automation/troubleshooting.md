# Возможные проблемы

Если автоматизация ничего не публикует, сначала откройте её **Журнал**: там будет **Пропущен** (так задумано) или **Ошибка** (нужно исправить). Ниже — частые случаи.

## В мастере нет сайтов

Сообщение: **Нет подключённых сайтов. Сначала установите плагин WordPress или Битрикс.**

Для новой автоматизации сайтом-источником может быть только сайт на WordPress (плагин версии 2.0 и новее). Для 1С-Битрикс новой автоматизации пока нет — используйте [классический автопостинг](./classic/bitrix.md). Как вариант без плагина, источником может быть [RSS-лента](./rss.md).

- Установите [плагин WordPress](/ru/start/wordpress.md) и войдите в него тем же аккаунтом, что в кабинете.
- В разделе **Интеграции** кабинета сайт должен быть в списке и со статусом «активен».
- Если сайт был отключён, подключите его заново из плагина на сайте: откройте в WordPress раздел **Автоматизация** и нажмите **Подключить снова** (см. [ниже](#сайт-отключили-в-интеграциях)).

## Сайт есть, но источник не настраивается

Сообщения вроде: плагин на сайте отключён или неактивен, сайт временно недоступен, или **откройте эту страницу из раздела настроек плагина на вашем сайте**.

Для настройки источника сайт должен быть доступен для серверов ParrotPoster. Проверьте:

- плагин на сайте включён и активен;
- сайт открывается по HTTPS, REST API WordPress не закрыт паролем (basic-auth), файрволом, защитой Cloudflare «под капчу», сайт не на закрытом IP;
- откройте мастер **из админки WordPress** (раздел **Автоматизация** плагина), а не только по прямой ссылке кабинета: так запросы идут тем путём, каким плагин работает на сайте.

Кнопка **Повторить** заново запрашивает типы записей. Если сайт не отвечает, мастер покажет стандартный список типов (**Показан список по умолчанию**); доступность сайта проверится уже при сохранении.

## Нет аккаунтов на шаге «Куда публиковать»

Подключите соцсеть в разделе **Аккаунты**: [инструкции по подключению](/ru/accounts/index.md). Если аккаунт требует переподключения, пройдите подключение ещё раз: иначе автоматизация не сохранится (**Выбран неактивный аккаунт**) или запуски будут с ошибкой аккаунта.

## Опубликовал запись на сайте — в журнале пусто

Подождите пару минут и обновите журнал (он обновляется сам, но не мгновенно).

- Для режима **Мгновенно** запись должна быть **опубликована**. Черновик, «на утверждении» или отложенная публикация событие не создадут.
- Автоматизация должна быть **Включена**. Пока она выключена, события принимаются, но запусков нет, и позже такие записи не наверстываются.
- Тип записей в автоматизации должен совпадать с типом записи на сайте.
- В режиме **Мгновенно** записи, опубликованные до создания автоматизации, не отправляются (на карточке подсказка **Автоматизация ждёт первую новую запись**). Для них нужны **Архив** или **Гибрид**.
- Фильтр на вкладке **Контент** не должен отсекать запись.
- Если у вас закончился тариф, автоматизация создаёт посты, но они не публикуются, пока тариф не продлён — проверьте раздел **Тарифы**.

## В журнале «Ждём опроса плагина»

Плагин на сайте периодически сам забирает задачи у ParrotPoster. До этого момента запуск ждёт. Интервал опроса подстраивается и составляет от 5 до 60 минут: он короче, когда задачи есть, и длиннее, когда их долго нет.

Если ожидание не заканчивается:

- на WordPress должен работать планировщик WP-Cron (или системный cron, который его запускает);
- сайт должен быть доступен из интернета, а REST API не закрыт файрволом, Cloudflare-проверкой, basic-auth или закрытым IP;
- плагин должен быть актуальной версии (2.0 и новее).

Если ожидание длится часами, напишите на [support@parrotposter.com](mailto:support@parrotposter.com).

## Статус «Пропущен»

Это не сбой: запуск осознанно ничего не опубликовал. Причина указана в колонке **Причина** и в деталях запуска (**Причина пропуска**).

| Что видите | Что сделать |
| --- | --- |
| **Нет подходящих элементов**, **Источник вернул 0 элементов** | Ослабьте отбор или опубликуйте запись нужного типа |
| **Нет подходящего элемента после фильтрации** | Условия отбора отсекают записи в начале очереди архива; ослабьте условия |
| **Условия pipeline не выполнены**, **Событие вне области pipeline** | Запись не подходит под отбор автоматизации |
| **Уже опубликовано ранее** | Эта запись уже обрабатывалась этой автоматизацией — дубль не создаётся |
| **Часть аккаунтов уже опубликована** | Пост создан только для аккаунтов, которых не было раньше |
| **Изменённые поля не затрагивают шаблон** | Изменили запись, но не то, что используется в шаблоне. Чтобы обновлять пост при любых правках, выберите **Запускать при любом событии** |
| **Обновление без связанного поста**, **Удаление без связанного поста** | Пост из этой записи не создавался (например, запись опубликована до автоматизации) — это не ошибка |
| **Архив исчерпан, триггер остановлен** / **…приостановлен** | Все подходящие записи разобраны. Нажмите **Возобновить**, когда появятся новые — см. [после настройки](./edit.md#выключить-возобновить-удалить) |
| **Архив исчерпан (цикл)** | Включён режим **Начать сначала**: этот запуск ушёл на смену круга, записи пойдут с начала |
| **Слишком рано после предыдущей публикации**, **Не прошёл минимальный интервал** | Сработал минимальный интервал между постами. Запись не потрачена и будет взята на следующем слоте |
| **Триггер выключен** | Автоматизация выключена |
| **Нет подходящих записей — дайджест за этот период пропущен**, **После фильтра элементов ничего не осталось**, **Набор записей не удовлетворяет условию дайджеста** | За период нет подходящих записей — дайджест пустым не публикуется |
| **Это окно уже было обработано (повтор)** | Этот период дайджеста уже опубликован (например, вручную) |
| **Публикация позже запланированного времени** | Пометка **Позже плана**: запуск начался уже после намеченного времени, пост ушёл сразу. Увеличьте **Запуск заранее** |

Допустимые часы публикации запуск не пропускают: пост просто переносится на ближайшее начало окна.

## Статус «Ошибка»

Откройте строку журнала: в **Детали ошибки** будет описание и код. Частые случаи:

- **Аккаунт неактивен или требует переподключения** / **Токен аккаунта отозван или истёк** — переподключите аккаунт в разделе **Аккаунты**.
- **Платформа требует медиа, но его нет** (**Instagram требует медиа**) — в шаблоне включите **Добавить медиа из статьи**, у записи должна быть картинка или видео.
- **Текст превышает лимит платформы** — сократите текст или добавьте обрезку к полю (**Обрезать по символам**).
- **Не выбраны аккаунты для публикации** — выберите аккаунты на вкладке **Публикация**.
- **В шаблоне не хватает обязательного поля**, **Ошибка рендеринга шаблона**, **Ссылка в шаблоне невалидна**, **Медиа из шаблона не найдено** — проверьте [шаблон](./template.md) и данные записи.
- **Ошибка доставки в соцсеть**, **Rate limit соцсети**, **Таймаут доставки**, **Исчерпаны попытки доставки** — ограничение или сбой самой соцсети; повторите позже, а при систематических ошибках проверьте аккаунт.
- **Плагин недоступен**, **Версия плагина несовместима**, **Callback URL плагина недоступен**, **Источник недоступен** — сайт недоступен ParrotPoster или плагин устарел: обновите плагин и проверьте доступность сайта.
- **Ошибка авторизации у источника**, **Источник вернул 404** — для RSS-ленты: проверьте URL и данные доступа.

Запуск можно повторить кнопкой **Запустить снова** в деталях запуска.

### AI не сработал

Если после публикации пост вышел **без** AI-обработки, это не ошибка, а запасной путь: в шагах запуска будет пометка **AI недоступен — использован исходный текст**. Причины: недействительный ключ своей модели, исчерпанная квота AI, **AI недоступен на текущем тарифе**, суточный лимит AI-вызовов. Подробнее в разделе [AI-обработка](./template.md#ai-обработка).

## «Архив пройден»

Все записи, подходящие под отбор, уже опубликованы. Нажмите **Возобновить**, если на сайте появились новые записи или вы расширили фильтр. Подробнее в [после настройки](./edit.md#выключить-возобновить-удалить).

## RSS-лента не публикует

- Первая успешная проверка только запоминает записи, что уже есть в ленте; публикуются только новые (если не включён **Импорт существующих записей**).
- Проверьте состояние ленты на вкладке **Публикация**: **Последняя проверка**, **Следующая проверка**. Сообщение **Лента отклонила учётные данные** — проверьте доступ и введите данные заново.
- За одну проверку публикуется не больше 20 записей, остальные ждут (сколько — видно в карточке).
- Правки записей заметны, только если лента отдаёт дату изменения.

Подробнее на странице [RSS-лента как источник](./rss.md).

## Посты уходят не туда или не с тем текстом

- Аккаунты задаются на вкладке **Публикация**.
- Текст будущих постов — шаблон на вкладке **Контент**. Уже созданные посты от правки шаблона не меняются.
- У сети может быть вкладка со своими настройками (Telegram, ВКонтакте, Facebook, MAX) или отдельный текст. Проверьте, нет ли **Есть переопределения** на вкладке нужной сети ([подробнее](./template.md#настройки-для-отдельных-сетей)).

## Сайт отключили в «Интеграциях»

Автопостинг с этого сайта приостанавливается. Автоматизации не удаляются, но ничего не публикуют. На странице **Автоматизация** появится сообщение **Автопостинг с сайта … отключён**.

Вернуть сайт можно из плагина WordPress: откройте раздел **Автоматизация** и нажмите **Подключить снова**. В кабинете кнопка этого сообщения — **Перейти в Интеграции**.

## Всё ещё не ясно

Напишите на [support@parrotposter.com](mailto:support@parrotposter.com) или через [поддержку в кабинете](/ru/assistant/support.md): укажите адрес сайта, название автоматизации и скриншот журнала с ошибкой.
