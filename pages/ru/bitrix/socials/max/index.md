# Подключение Max

::: tip Бета
Интеграция с мессенджером Max находится в стадии бета-тестирования. Если что-то пойдёт не так, напишите на [support@parrotposter.com](mailto:support@parrotposter.com).
:::

К подключению канала или группы в Max в ParrotPoster есть два подхода — с ботом сервиса или со своим ботом. Ниже — общая инструкция; затем — что сделать в модуле.

<!-- @include: ../../../socials/max/index.md#max-instructions -->

## Подключение в модуле

Выполнив подготовительные шаги, откройте в модуле страницу **Аккаунты** и нажмите **Подключить** для мессенджера **Max**.

В открывшемся окне выберите способ подключения:

- для **бота ParrotPoster** укажите ссылку или ID канала/группы и нажмите **Подключить**;
- для **своего бота** вставьте токен, дождитесь списка каналов, выберите нужный и нажмите **Подключить**.

Готово — аккаунт Max появится в списке, и можно публиковать посты из Битрикс через ParrotPoster.
