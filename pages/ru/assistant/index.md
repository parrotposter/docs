# ParrotAI — AI-помощник

ParrotAI — встроенный AI-помощник ParrotPoster. Он отвечает на вопросы о работе сервиса и может помочь разобраться с ошибкой публикации. Помощник доступен в кабинете и во встроенных страницах плагинов, если включён для вашего аккаунта.

::: warning Важно знать
- Отвечает AI, человек к диалогу ParrotAI не подключается.
- Ответы могут быть неточными.
- Чтобы обратиться к человеку, используйте [поддержку](./support.md).
:::

## Как открыть

На страницах кабинета есть кнопка **Спросить ParrotAI** (с меткой **AI**). Нажмите её — откроется рабочая область диалога. На компьютере это панель поверх страницы, на телефоне — во весь экран. Пока ParrotAI готовит ответ, можно продолжать пользоваться страницей.

## Диалог

1. Введите вопрос в поле **Задайте вопрос** и нажмите **Отправить**.
2. Пока идёт ответ, виден статус **Думаю…**.
3. Под каждым ответом ParrotAI есть кнопки «палец вверх» (**Ответ помог**) и «палец вниз» (**Ответ не помог**). Нажатую кнопку можно нажать ещё раз, чтобы отменить оценку. Оценка не закрывает диалог — его можно продолжить в любой момент. Оценки используются для улучшения ответов. Если ответ не подошёл, задайте уточняющий вопрос.
4. Для другой темы нажмите **Новый диалог** (неотправленный текст будет потерян, потребуется подтвердить **Начать новый**). Правило: один диалог — одна проблема.

## История диалогов

Кнопка **История** открывает **Ваши недавние диалоги**. Выберите диалог, чтобы открыть его и продолжить переписку; **Загрузить ещё** подгружает более старые. Диалог без заголовка называется **Диалог без названия**. Из списка можно вернуться через **Вернуться к диалогу**, закрыть панель — **Закрыть**. Если диалогов ещё нет — **Начать первый диалог**.

## Что умеет ParrotAI

- объяснять, как настроить и использовать функции ParrotPoster;
- помогать разбирать ошибки публикации.

## Ограничения и сообщения

Если ParrotAI не может дать ответ, он объяснит причину:

| Сообщение | Что делать |
| --- | --- |
| Это вне того, с чем ParrotAI может помочь | Задайте вопрос о ParrotPoster |
| ParrotAI недостаточно уверен, чтобы дать надёжный ответ | Уточните вопрос: что вы делали и что ожидали увидеть |
| Здесь нужен человек: вопрос про доступ или конфиденциальность<br>Вопросы по оплате решает поддержка<br>Похоже на проблему продукта — лучше в поддержку | Напишите в [поддержку](./support.md); по оплате см. также [Тарифы и оплата](/ru/billing/index.md) |
| Модель AI сейчас недоступна | Повторите позже |
| У AI-помощника закончился лимит использования | Повторите позже |
| ParrotAI не смог завершить ответ | Повторите вопрос |
| Не удалось отправить запрос. Попробуйте ещё раз. | Повторите отправку |
| ParrotAI пока недоступен | Помощник не включён для вашего аккаунта — ответы ищите в этой документации |

## Передача в поддержку

Нажмите **Написать в поддержку**: откроется форма обращения с подставленным текстом из диалога. Подробнее — [Поддержка](./support.md).
