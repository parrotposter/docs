# Вовлечённость: лайки, комментарии, просмотры

ParrotPoster собирает показатели опубликованных постов из соцсетей и показывает их прямо в разделе **Посты** — не нужно открывать каждую соцсеть.

## Где смотреть

- **В списке постов** на карточке опубликованного поста показаны суммарные показатели по всем аккаунтам: **Лайки и реакции** (подсказка «Лайки и реакции суммарно»), **Комментарии** и **Просмотры**. Пока метрики ещё не получены, строки на карточке нет.
- **В окне просмотра поста**, в блоке **Результаты публикации**: показатели по каждому аккаунту отдельно, рядом со ссылкой **Посмотреть пост**. Над блоком указано, когда данные обновлялись последний раз («Обновлено: …»).

## Какие показатели даёт каждая соцсеть

| Соцсеть | Что показывается |
| --- | --- |
| ВКонтакте | лайки, комментарии, просмотры |
| Одноклассники | лайки, комментарии |
| Facebook | реакции (по видам), комментарии |
| Instagram | лайки, комментарии (просмотры — если их отдаёт способ подключения) |
| Telegram | реакции (по эмодзи); комментариев и просмотров нет |
| MAX | только просмотры |

Если соцсеть не отдаёт какой-то показатель, он просто не показывается. Реакции Telegram и Facebook выводятся по видам («❤ 5», «👍 3»); пользовательские эмодзи Telegram показываются общим значком с подсказкой «Кастомный эмодзи». В суммарной строке карточки реакции складываются с лайками.

## Как обновляются данные

Метрики запрашиваются автоматически: первый раз вскоре после публикации, далее чем старше пост, тем реже. Поэтому у свежего поста цифры меняются чаще.

Чтобы получить свежие данные немедленно, откройте пост и нажмите **Обновить метрики** над результатами публикации. Кнопка работает не чаще одного раза в 5 минут для каждого поста: до этого она неактивна, а подсказка говорит «Повторно доступно после …».

## Статусы показателей

В строке аккаунта вместо цифр может быть пояснение:

| Что видно | Что значит |
| --- | --- |
| «Ожидаем метрики…» | пост только что опубликован, первых данных ещё нет |
| «Недоступно» | для этого поста или аккаунта показатели не собираются (подсказка при наведении объясняет причину) |
| «Не удалось обновить метрики» | последняя попытка не удалась; показаны прошлые данные, повтор будет позже |
| «Лимит обновлений, показаны последние данные» | соцсеть попросила не обращаться так часто; показаны последние полученные данные |

::: tip
Показатели не считаются мгновенно и могут отставать от соцсети на время до следующего опроса. Для самых актуальных цифр используйте **Обновить метрики**.
:::
